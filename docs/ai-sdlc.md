# How this repository was written

This repository was written in a Grok Build session. It was not written in Claude Code.

The session produced the package, the tests, the diagrams, and the measurement in `benchmarks/latest.json`. Numbers in the README are copied from that file or from pytest assertions that call the same functions. A figure that was not produced by a command in this session is not claimed.

Review before treating any workflow as more than a draft. The deployment decision remains NO-GO until a later environment actually runs the image, the database, and the identity provider, and until a separate clinical review exists. This repository does not contain that review.
